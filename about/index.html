    关于本站

    Everyone Create Community（每个人创作社区）的官方文档站，托管于 GitHub Pages，访问地址 docs.git.eocc.top。

    站点定位

    本站是社区的公共知识库与协作文档中心，集中存放社区的使用手册、版本更新记录与开发者文档，是了解社区、参与共建的统一入口。

    板块 内容 适合谁
    版本更新日志 每个版本的新增功能、问题修复与社区公告 所有成员
    开发者文档 文档写作、站点维护与项目开发发布流程 想参与共建的成员

    站点是怎么运作的

    本站由 MkDocs 构建，使用 Material 主题：

    • 页面源文件为 Markdown，由 MkDocs 编译为纯静态 HTML
    • 编译产物发布到 GitHub 仓库 eoccc/eoccc.github.io，由 GitHub Pages 对外服务
    • 自定义域名由仓库根目录的 CNAME 文件指定

    整个过程没有后端服务器：搜索、导航等功能都在构建期生成、由浏览器端 JS 完成。

    核心功能

    功能 说明
    全站搜索 MkDocs 内置搜索（lunr），纯前端实现，无需后端
    响应式界面 Material 主题，桌面 / 移动端自适应
    版本化管理 全部内容由 Git 管理，历史可追溯、可回滚
    自动化部署 合并后构建为纯静态 HTML 发布到 GitHub Pages

    维护与反馈

    本站的写作规范、提交流程与站点配置，统一收录在开发者文档中：

    • 想撰写或修订文档 → 看环境搭建与 Markdown 写作规范
    • 想提交改动 → 看提交与上线流程
    • 想调整导航或站点结构 → 看导航与站点配置
    • 想开发并发布软件包 → 看 GitHub 开发与软件包发布流程

    发现文档错误或有改进建议，欢迎在 GitHub 仓库提交 Issue 或 Pull Request。

    注意事项

    • 仓库根目录的 CNAME 为自定义域名配置，请勿删除，否则域名解析失效
    • 仓库根目录的 release/update/ 为版本更新日志子站，其内容生成流程独立于 MkDocs，改动请联系维护者
