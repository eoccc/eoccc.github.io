    关于本站

    EveryOne Create Co-Creation Community（人人共创社区） 的官方文档站，托管于 GitHub Pages，访问地址 docs.git.eocc.top。

    站点方向与功能

    本站是社区的公共知识库与协作文档中心，内容涵盖：

    • 社区文档：社区介绍、行为准则与协作规范
    • 项目维基：各共创项目的使用说明、开发指南与 FAQ
    • 教程与分享：成员贡献的经验总结、技术教程与最佳实践

    核心功能：

    功能 说明
    全站搜索 MkDocs 内置搜索，纯前端实现，无需后端
    响应式界面 Material for MkDocs 主题，桌面 / 移动端自适应
    版本化管理 全部内容由 Git 管理，历史可追溯、可回滚
    自动化部署 提交 Markdown 后由 MkDocs 构建为纯静态 HTML 发布

    贡献方法

    欢迎每一位成员参与共建！所有页面源文件均为 Markdown，位于仓库的 docs/ 目录：

    1. Fork 仓库 eoccc/eoccc.github.io
    2. 新建分支，编辑或新增 docs/*.md 文件
    3. 提交 Pull Request，说明改动内容
    4. 经审核合并后站点自动更新

    注意：docs/CNAME 为自定义域名配置，请勿删除。
