    Wiki

    本站的 Wiki 板块，用于收录社区成员共同维护的条目式内容：操作指引、环境备忘、常见配置、经验速查等。

    说明：本页为入口页，条目内容按社区贡献陆续补充。当前如需查阅已成体系的内容，可先前往常见问题与开发者文档。

    这个板块放什么

    Wiki 适合承载条目化、可独立查阅、由多人持续补充的内容：

    适合放在 Wiki 更适合放在别处
    零散但实用的操作备忘 成体系的教程 → 开发者文档
    特定环境 / 平台的配置要点 常见问答 → 常见问题
    外部工具、资源的使用速记 版本变更记录 → 版本更新日志
    成员贡献的经验与技巧 社区规则条文 → 社区公约

    如何贡献条目

    Wiki 内容与站点其他页面采用同一套协作方式：

    1. 按环境搭建准备好本地环境
    2. 依Markdown 写作规范撰写内容
    3. 按提交与上线流程提交 Pull Request

    提 Issue 或写 PR 时，仓库已提供结构化模板，填写提示见提交与上线流程 · 提 Issue 与写 PR。
