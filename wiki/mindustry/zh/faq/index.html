    常见问题

    如何与好友/敌人进行多人游戏？

    如果你们在同一个 Wi-Fi 或热点网络中，操作很简单。开始一局游戏，打开暂停菜单并点击「主持多人游戏」按钮，你的游戏就会对同一网络内的所有人可见。其他设备要加入，点击「开始游戏 > 加入游戏」即可。如果由其他玩家主持，游戏会出现在服务器列表中。

    找不到好友的多人游戏！

    如果你确信在同一网络却仍找不到对方的游戏，可以考虑改用 Wi-Fi 热点而非公共网络——部分公共 Wi-Fi 会直接禁止局域网内服务发现。

    如果你已使用 Wi-Fi 热点却仍找不到好友的游戏，可以尝试直接通过 IP 连接。不用再去搜索游戏，而是找到主持设备的局域网 IP（请按你所用的具体设备自行查询查看方式），让另一位玩家在「开始游戏 > 加入游戏 > 添加服务器」中填入该 IP。

    如何跨网络与他人联机？

    你需要做端口映射，并把你的 IP 分享给其他玩家。参见此处的指南。

    可以考虑使用公共服务器，例如游戏中已内置的那些。

    如何搭建专用服务器？如何做端口映射？

    参见本指南。

    PC 玩家能与 iOS/Android 玩家一起玩吗？

    可以。Mindustry 完全跨平台。只要所有设备运行的是同一版本，任意设备都能与其他设备连接。

    如何导入地图？

    首先，要确认地图与你的游戏版本兼容。如果你运行的是 Mindustry 4.0 或更高版本，则需要 .msav 格式的地图文件。 把文件下载到设备后，打开 Mindustry 主菜单，选择「编辑器 → 导入地图」（位于界面上方）。找到地图所在目录，选中文件并点击「打开」。

    注意，文件选择器只会显示 .msav 扩展名的文件。如果找不到文件，请确认目录正确、扩展名无误。另外，Discord 有时会在下载时去掉扩展名，这种情况下需要用文件管理器手动补上扩展名。

    如何导出地图文件？

    在编辑器中打开你的地图，打开菜单并点击「导出」，选择一个目录，输入文件名后点击「保存」。

    Mindustry 能在树莓派上运行吗？

    虽然游戏理论上可以支持，但实际情况是不支持树莓派。

    不过，只要安装了正确版本的 Java，专用服务器是可以在树莓派上运行的。

    游戏的源代码在哪里？

    在 GitHub 上： https://github.com/Anuken/Mindustry

    Anuke 是一个人开发这款游戏的吗？

    大体上是的。音乐、美术与程序都由我完成，翻译则来自社区贡献者。 也有人通过在 GitHub 提交 pull request 来贡献代码，这些人在 Discord 上带有 Contributor 身份组。此外还有许多人参与 Wiki 与文档的编写。

    如何加入 Google Play 测试计划？

    打开 Mindustry 的 Google Play 页面，滚动到底部并点击「加入测试」。点击后测试版可能需要一段时间才会开放，请耐心等待——这一过程由 Google 自动处理，我无法控制其速度。

    无法连接服务器／游戏版本过旧，该怎么办？

    如果你在 Android 上使用 Google Play，请等待更新推送。新版本通常先更新再发公告，但 Google 可能需要数小时来处理，请耐心等待。

    如果你在 iOS 上，情况类似，只是等待时间更长。iOS 版本的发布周期更久，而且即使上传完成，Apple 还需要 1-2 天来审核每个版本。

    如果你使用桌面版，只需通过本频道顶部的链接进入 itch.io 重新下载游戏即可。

    更新不应重置进度。

    Anuke 和 Anuken 是两个人吗？

    他们其实就是同一个人。当 "Anuke" 已被占用时，Anuke(n) 就会使用 "Anuken" 这个名字。

    当 Anuke 这个用户名被占用时，我通常使用 Anuken。——Anuken

    游戏免费，为什么 Steam 和 iOS 上要收费？

    Steam 与 iOS 版本收费，是因为这是支持 Anuke 的一种方式，而且它们具备免费版没有的功能，例如：

    • 地图、模组与蓝图浏览器

    • 通过 Steam 多人游戏实现安全无缝的联机（无需端口映射）

    • 启动时公开展示服务器

    • 成就系统

    • 数据统计

    • 通过 Steam 实现云存档与进度同步

    • Steam 社区

    我能为游戏做些什么贡献？

    • 最简单的方式是在我们的 Discord 服务器中提出建设性反馈并参与讨论（最好与游戏相关）。

    • 在 GitHub 仓库中报告你发现的 Bug。请务必正确使用模板，这样能让你的 issue 更规范、更符合统一格式，也会减轻 Anuke 的负担。如果你会 Java 编程，欢迎帮忙修复这些 Bug 并提交 PR。

    • 如果你想提供资金支持，可以在 Itch.io 页面向 Anuke 捐赠，也可以在 Steam 上购买游戏。

    • 如果你精通 Mindustry 尚未支持的语言，或想为已有语言作出贡献，请到 #translations 频道咨询。你可以参与现有语言包的翻译，并在游戏仓库中提交 PR。

    • 如果你想为本 Wiki 做贡献，请在仓库中提交 PR，仓库链接位于右上角。
