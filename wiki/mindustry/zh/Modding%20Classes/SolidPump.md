# SolidPump

## SolidPump

*继承自 Pump*

从固体制造液体并消耗电力的泵。仅对实心地板块有效。

| 字段 | 类型 | 默认值 | 备注 |
|---|---|---|---|
| result | Liquid | water |  |
| updateEffect | Effect | none |  |
| updateEffectChance | float | 0.02 |  |
| rotateSpeed | float | 1.0 |  |
| baseEfficiency | float | 1.0 |  |
| attribute | Attribute | null | 计算产出时检查的属性。 |
| rotatorRegion | TextureRegion | null |  |
