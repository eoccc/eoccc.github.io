    RadialEffect

    继承自 Effect

    Renders one particle effect repeatedly at specified angle intervals.

    字段 类型 默认值 备注
    effect Effect none
    rotationSpacing float 90.0
    rotationOffset float 0.0
    effectRotationOffset float 0.0
    lengthOffset float 0.0
    amount int 4
