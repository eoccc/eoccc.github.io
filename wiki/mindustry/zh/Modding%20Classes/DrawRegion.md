# DrawRegion

## DrawRegion

*继承自 DrawBlock*

| 字段 | 类型 | 默认值 | 备注 |
|---|---|---|---|
| region | TextureRegion | null |  |
| suffix | String | "" |  |
| name | String | null | 设置后覆盖区域名称。 |
| color | Color | null |  |
| spinSprite | boolean | false |  |
| drawPlan | boolean | true |  |
| buildingRotate | boolean | false |  |
| rotateSpeed | float | 0.0 |  |
| x | float | 0.0 |  |
| y | float | 0.0 |  |
| rotation | float | 0.0 |  |
| layer | float | -1.0 | 小于等于 0 的数值都会禁用图层切换。 |
