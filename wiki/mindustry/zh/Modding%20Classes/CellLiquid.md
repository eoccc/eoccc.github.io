# CellLiquid

## CellLiquid

*继承自 Liquid*

会在其水洼中绘制格子的液体。

| 字段 | 类型 | 默认值 | 备注 |
|---|---|---|---|
| colorFrom | Color | ffffffff |  |
| colorTo | Color | ffffffff |  |
| cells | int | 6 |  |
| spreadTarget | Liquid | null |  |
| maxSpread | float | 0.75 |  |
| spreadConversion | float | 1.2 |  |
| spreadDamage | float | 0.11 |  |
| removeScaling | float | 0.25 |  |
