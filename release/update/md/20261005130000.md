# 构建源入库与站点功能接线

**更新时间**：2026-10-05-13:00:00
**版本类型**：正式发布 / 工程结构
**适用范围**：Everyone Create Community（EOCC共创社区）GitHub Pages 文档站

---

## 一、版本概述

本版为**工程结构版本**，不改变站点内容与导航，集中解决三件事：把长期游离于仓库之外的 MkDocs 构建源纳入版本管理、让两个已写好却从未生效的站点脚本真正上线、消除站点自定义域在各处配置中的不一致。

---

## 二、构建源入库

此前仓库只存放 MkDocs 构建产物（HTML 直存），源文件位于构建机本地，仓库无法独立复现构建。本版将构建源完整纳入仓库，作为开发者模板：

| 新增路径 | 内容 |
|---|---|
| `mkdocs.yml` | 站点配置：导航结构、主题、扩展与自定义资源声明 |
| `docs/` | 全部 Markdown 源文件与静态资源（约 6900 个文件） |
| `overrides/` | 主题模板覆写（`partials/nav.html`、`partials/copyright.html`） |

同时新增 `.gitignore`，排除本地构建产物 `site/`、工具缓存 `.sitemap-cache.json` 与编辑器临时文件，避免误提交。

> 构建产物仍按原有方式发布在仓库根目录，仓库现在同时具备「源」与「产物」两层，可独立完成构建。

---

## 三、站点功能接线

仓库中存在两个纯原生 JS 脚本，样式亦已就绪，但从未被任何页面引用，实际处于失效状态。本版完成接线：

1. **版本更新提醒**（`js/eocc-version-check.js`）：读取 `data/site-info.json`，与 Cookie 中记录的上次访问版本比对，版本变化时在右下角弹出可关闭的非侵入式提醒条；同时回填页脚与侧边栏的版本号。
2. **图片放大**（`js/eocc-image-zoom.js`）：为正文中的示意图、流程图提供点击放大预览，支持 Esc 关闭与键盘操作。

接线方式为在 `mkdocs.yml` 中声明 `extra_javascript`，并补齐 `css/eocc-brand.css` 中缺失的提醒条、放大遮罩与版本号样式。

---

## 四、自定义域统一

站点自定义域在配置中曾出现三处不一致：`CNAME` 为 `docs.66131466.xyz`，而站点地图、页面 canonical 与部分文档文案仍指向旧域名 `docs.git.eocc.top`，导致搜索引擎获取的地址无法访问。

本版将全站统一为 **`docs.66131466.xyz`**，涉及站点配置 `site_url`、站点地图生成脚本、仓库 Issue / PR 模板、开发者文档与相关配图。
