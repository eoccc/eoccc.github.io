#  v1.24-2250-beta
- 本次更新修复了二个问题，两项规则迎来了修改
- 更新后可能还会有许多关于设备适配的问题，若有其他想反馈的内容也可在此[电子邮箱](mailto:Kevin.znt@qq.com)反馈
## 修复内容
 1. 修复了：在未开启 VPN 的环境下，Markdown 渲染页面无法加载、渲染失败的问题
之前必须开国外线路才能正常显示 MD 内容，现在不开 VPN 也能 100% 正常加载、正常渲染。
2. 杂项
    - 更新了 Markdown 渲染引擎到最新稳定版，修复了旧版潜在的渲染异常、格式错误问题。
   - 提升了页面在国内网络环境下的整体稳定性与可用性。
## 更新内容
1. 更新日志管理后台（release.php）功能优化需求
- 原表单中「发布时间」「生效时间」需手动填写，操作繁琐
- 现改为时间输入框新增「自动获取当前时间」按钮，支持 2026-03-22 （中横线）、 2026/03/22 （斜杠）两种格式
2. Markdown渲染库本地化与版本升级需求
- 原使用 marked.js 11.1.1 （2023年版）CDN资源，国内不开VPN加载失败
- 现改为将MD渲染逻辑本地化，彻底脱离外网依赖，同时升级到最新版，实现自定义语法规范的完全可控
## 功能优化
1. 修复了：更新日志发布/编辑时，发布时间、生效时间需要手动输入的不便问题
增加一键自动获取当前时间功能，减少输入错误、提升发布效率。
2. 修复了：Markdown 渲染库依赖外部 CDN 导致的加载不稳定、加载缓慢、不可控问题
改为本地加载后，速度更快、更稳定、不再受第三方服务影响。
