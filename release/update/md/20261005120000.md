## 一、版本概述

本次更新完成 Wiki 板块的结构性重构：重新定义 Wiki 首页的定位与内容版图，将「编程语言」按语言拆分分组，把 Mindustry 中文版侧边栏的 805 个英文标签全部汉化，并新增 Markdown 语法详解栏目。同时修复了编程语言分支子页面的图片链接失效问题。

本版为**预发布版本**，用于在正式发布前验证重构后的导航结构与内容组织。

---

## 二、Wiki 首页重构

原首页定位模糊、措辞偏口语化，作为 Wiki 知识库的入口已无法承担指引作用。本次按实际内容规模重新改写：

1. **明确板块定位**：开篇即说明 Wiki 承载「条目式、成体系、可长期沉淀」的技术知识，并划清与开发者文档、常见问题的分工边界。
2. **给出内容版图**：以「两大知识分支」表格呈现 Mindustry 内容体系（1621 页）与编程语言与数据格式（5 页）的规模与适用人群。
3. **新增配图**：绘制内容版图示意图 `wiki-map.svg`，直观展示两个分支的构成与页面分布。
4. **细分查阅路径**：按「查属性 / 写模组 / 写补丁 / 选格式 / 对照英文」等实际目的给出入口，替代原先笼统的引导。
5. **补充组织原则**：将条目化、可交叉引用、术语统一、代码不翻译、与上游同步五条约定明示。
6. **清理口语化措辞**：移除「这个板块放什么」「欢迎认领」等表述，改用规范的书面说明。

## 三、导航结构规范化

### 3.1 编程语言分支

原结构将 JSON 与 HJSON 页面平铺在「编程语言」下，后续加入新语言时会打乱既有层级。本次调整为：

- 「编程语言」下新增 **JSON** 折叠分组，收纳 JSON 基础、HJSON 基础、JSON 与 HJSON 对比三个页面
- 新增「发展历程与前景」页面，独立讲述 JSON 的标准化里程碑与现代生态
- HJSON 归入 JSON 分组，因其为 JSON 的超集，二者共享同一数据模型

后续新增语言（如 YAML、TOML）只需添加同级分组，不影响现有结构。

### 3.2 Mindustry 中文版侧边栏汉化

中文版侧边栏原有 805 个英文标签，本次全部汉化：

| 分组 | 数量 | 示例 |
|---|---|---|
| 游戏内容 | 530 | Graphite Press → 石墨压缩机、Copper Wall → 铜墙 |
| 模组类文档 | 262 | 采用「中文 类名」格式，如 Block → 方块 Block |
| 模组开发 | 9 | Modding Introduction → 模组开发入门 |
| 逻辑 | 4 | Glossary → 术语表 |

模组类文档保留类名英文，以确保与源码、API 的对应关系可检索。

## 四、新增 Markdown 语法详解

在「开发者文档 → 文档共建」下新增 Markdown 语法详解栏目，共 6 个页面：

| 页面 | 内容 |
|---|---|
| 总览 | 学习路径与贯穿全篇的两条原则 |
| 基础语法 | 标题、段落、强调、列表、链接、图片、引用、分隔线 |
| 进阶语法 | 表格、代码块、转义、HTML 混排、属性列表 |
| 本站渲染规则 | 支持与不支持的语法、替代方案、路径规则 |
| 细节与常见错误 | 空行、缩进、符号冲突、链接图片等高频踩坑点 |
| 速查表 | 一页速览，写作时对照使用 |

内容基于本站实际启用的扩展逐一实测后编写，明确标注删除线、任务列表、脚注、admonition 等语法在本站**不生效**，并给出替代写法。
