# 版本：v8 Build 156.2 - Beta（预发布版本）
- 此版本官方修复了一些小问题，Everyone Create已将官方的v8-156.2版本进行汉化
- 若想查看原内容请点击[原链接](https://github.com/Anuken/Mindustry/releases/tag/v156.2)
##  问题修复
- 由于模组  `scheme-size`  旧版本会频繁导致启动崩溃，已将其加入黑名单
​
- 更新了「滨海船坞（Littoral Shipyard）」区域的提交内容
​
- 修复了长按载荷拾取/投放键会导致服务器速率限制的问题
​
- 修复了状态效果在界面中显示比例不正确的问题
​
- 允许客户端出现“偶发”UDP错误，这可能在低优先级数据包未正常到达时，带来更稳定的游戏体验
