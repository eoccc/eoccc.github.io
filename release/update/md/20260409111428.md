# Mindustry v8 Build 157 - Beta 更新公告

> **版本类型：测试版（Pre-release）**
> 发布时间：2026-04-09-23:12:45

---

## 版本说明
如果一切顺利，本版本将是 v8 正式版发布前的最后一个测试版本。Build 157 部署后，我们将预留数日时间修复已发现的重大问题，随后发布 Build 157.1 作为正式非测试版本。

---

## 更新内容
### 功能调整
- 优化桌面端全屏实现逻辑，统一采用无边框全屏模式
- 移除冗余的「无边框全屏」设置项
- 移动端新增 JavaScript 控制台（需在设置中手动开启）
- 调整 Serpulo 星球发光红色导线块显示逻辑：当核心被摧毁或区域被占领时，附近导线块将变暗
- 为从 Build 146 升级的用户添加区域迁移警告
- 为缺失描述的区域补充说明文本
- 调整 Serpulo 星球超级基地布局，新增中心区域地图提交入口
- 隐藏 Serpulo 星球部分区域

### 问题修复
- 修复 Windows 端窗口缩放相关的多项问题
- 修复暂停状态下环境音效重复播放的问题
- 修复服务器端位置标记无法过滤的问题
- 修复非无头服务器在特定条件下，远程单位在墙体附近异常爆炸的问题
- 修复玩家单位在特定场景下被操控时出现瞬移的问题
