## 二、同业事件事实说明
近期圈内有同业开发者，自行推出 Mod 可视化编程编辑器，以电脑端 EXE 打包形式对外分发；工具底层游戏官方 **GPL 3.0** 开源的 Mod 解析核心代码，封装图形化操作界面，大幅度降低普通用户 Mod 创作入门门槛，延伸了整个Mindustry社区创作的覆盖维度。

该事件客观现状说明：
1. 同业工具填补了社区可视化编辑领域的空白，让更多普通爱好者能近距离接触、了解 Mod 开发逻辑，为整个游戏社区生态建设贡献了正向价值；
2. 工具打包体量臃肿，安装包远超官方原版程序大小，含大量运行环境冗余依赖，工程精简、架构优化意识不足；
3. 我方与该同业开发者**无任何前期交集、无技术合作、无项目绑定**，双方技术栈、开发理念、产品定位、设计路线完全不同；
4. 圈内已有社区成员自发问询，对比对标、倡议合作、催促跟进开发，已形成常态化舆论裹挟。

## 三、我方正式立场与个人表态
面对圈内热议、用户问询及合作提议，EOCC共创社区统一正式表态：
**不评价、不对标、不跟风，坚守自身节奏，不参与同业无意义内卷与人情拉扯。**

1. **尊重欣赏同业贡献**
我方充分认可、由衷欣赏同业开发者的付出与成果，尊重其独立创作、独立发布、独立运营的选择。该工具客观上降低了 Mod 创作门槛，契合共创社区「普及技术、落地想法」的内核，为整个社区生态承担了一份建设责任。

2. **立足现实划定精力边界**
本人现阶段正值学业关键周期，面临中考备考与长期学业规划，需优先以现实生活、学业成长为核心。
无多余精力、无额外时间，涉足陌生编程语言体系、适配非同源技术栈，也不愿介入原本无任何交集的同业项目合作与圈内人情纷争。

3. **坚持自研路线不依附**
我本身不熟悉对方所使用的 C 系技术栈，也无意强行融入对方开发架构；既不刻意对标跟风，也不贸然组队合作。
未来若对方开源协议宽松（MIT/GPL 等），可仅参考产品交互习惯与逻辑思路；亦可完全抛开现有范式，从 UI 交互、星球创建、科技树编排、单位属性可视化、标签联动约束等层面，完全自研一套属于 EOC 理念的跨端可视化编辑体系。

4. **顺其自然尊重用户选择**
当前阶段用户可自由使用同业现有工具，无需等待、无需倒逼我方跟进节奏。我会按照自身生活状态、时间安排、开发步调稳步推进，不被外界舆论带偏节奏。
