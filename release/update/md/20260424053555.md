## 一、版本概述
本次 `v1.24-2256-Beta` 为功能新增、体验优化、问题修复与上游大面积改动引发的全面升级，覆盖 Everyone Create 共创社区全平台。核心解决 marked.js 升级导致的 Markdown 渲染异常，恢复加粗、斜体、删除线等标准语法正常解析；同步新增网页游戏、资源镜像UI图标与详情分支页，更新 Mindustry 资源至 v8-157.3；底层完成服务器内核、插件、Java 版本升级，将 Mindustry 服务器转为公益免费公众服，并新增后台安全风控、统一全站渲染与界面体验。本次升级受上游大幅改动影响，涉及多项底层调整，整体实现问题修复、功能扩充、体验升级、服务公益化四大目标。
