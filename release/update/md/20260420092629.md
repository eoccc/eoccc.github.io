## 二、关于第三方资源整合站的事实说明

该行为存在以下**严重问题**：
1. 未经许可使用 EOCC共创社区的资源、链接、服务成果，属于实质性**盗用**；
2. 未在站点任何位置标注来源及版权信息，无视原创方合法权益；
3. 在页面标注“需自行证明链接可用性与风险性”，将**全部责任与风险**转嫁给 EOCC共创社区；
4. 自身**不承担**任何实际的数据分发、资源维护、合规核查、安全保障与版权责任，却**独享**曝光、流量与声誉。


EOCC共创社区此前已向该方提供极为优厚的友好合作方案，包括~~免除技术顾问费用~~、开放全部 CDN 与 API 使用权、提供项目股权分红等，均被明确拒绝。

- 第三方站点因链接失效、内容违规、平台处罚等引发的一切问题；

## 五、我方立场与后续措施
EOCC共创社区尊重并支持所有开发者独立创作、独立建站、自主运营的权利，但坚决反对：
