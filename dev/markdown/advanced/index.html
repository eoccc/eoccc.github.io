    进阶语法

    本页讲解表格、代码块、转义、HTML 混排等进阶写法。这些语法在写技术文档时使用频率很高。

    表格

    基本写法

    表格由表头行、分隔行、数据行组成：

    | 名称 | 说明 |
|---|---|
| 项目 A | 第一个项目 |
| 项目 B | 第二个项目 |

    渲染效果：

    名称 说明
    项目 A 第一个项目
    项目 B 第二个项目

    三个组成部分

    部分 作用 必需
    表头行 列标题 是
    分隔行 --- 组成的行，标记表格开始 是
    数据行 表格内容 否（可只有表头）

    分隔行不能省略。少了它，整段会被当成普通文字：

    | 名称 | 说明 |
| 项目 A | 第一个项目 |      ← 没有分隔行，不会渲染成表格

    对齐方式

    在分隔行中用冒号控制列对齐：

    | 左对齐 | 居中 | 右对齐 |
|:---|:---:|---:|
| 内容 | 内容 | 内容 |
    写法 效果
    :--- 左对齐
    :---: 居中
    ---: 右对齐
    --- 默认（通常左对齐）

    列数必须一致

    每行的竖线数量应相同。列数不匹配会导致渲染错乱：

    | A | B | C |
|---|---|---|
| 1 | 2 |          ← 少了 C 列，渲染可能异常

    实用建议：不必强求源码里竖线对齐美观，但竖线数量必须一致。

    单元格内的内容

    内容 写法
    行内代码 `代码`
    粗体 **文字**
    链接 [文字](地址)
    竖线字符 用 \| 转义

    表格内不能直接写竖线，必须转义：

    | 运算符 | 说明 |
|---|---|
| `\|` | 逻辑或 |

    单元格内不能换行

    单元格里的换行会被吞掉。需要多行内容时：

    • 拆成多列
    • 改用列表或段落表达
    • 用 <br> 强制换行
    | 项 | 说明 |
|---|---|
| A | 第一行<br>第二行 |

    代码块

    围栏式（推荐）

    用三个反引号包裹，并标注语言：

    ```json
{
  "name": "example"
}
```

    标注语言后，本站会启用语法高亮与复制按钮。常用语言标识：

    标识 用途
    json JSON 数据
    yaml YAML 配置
    markdown Markdown 源码
    java Java 代码
    js JavaScript
    bash Shell 命令
    text 纯文本（不高亮）
    html HTML

    不确定用什么时，用 text，至少不会高亮错误。

    缩进式

    用四个空格缩进表示代码块：

        这是缩进式代码块

    本站推荐围栏式：缩进式无法标注语言，且在列表中容易与嵌套混淆。

    代码块内的特殊字符

    代码块内的 Markdown 符号不会被解析，这是它最实用的特性：

    ```markdown
# 这个标题不会真的变成标题
**这个粗体不会真的变粗**
```

    代码块内出现反引号

    内容含三个反引号时，外层用四个反引号：

    ````markdown
```json
{"a": 1}
```
````

    本站的汉化规则（重要）

    本站对 Mindustry 相关文档有额外规定：

    位置 是否翻译
    代码块内容 不翻译（代码、配置、脚本、变量、指令原样保留）
    代码块内的注释 翻译
    正文、标题、列表、表格 翻译
    类名、字段名、变量名 保留英文

    即：代码是给机器读的，保持原样；注释是给人读的，翻译。

    转义

    在符号前加反斜杠 \，让它按字面显示：

    \* 不是列表，是星号
\# 不是标题
\| 表格里的竖线
\_ 下划线
\` 反引号
\[ \] 方括号

    需要转义的常用字符：

    字符 转义写法
    * \*
    _ \_
    # \#
    ` \`
    [ ] \[ \]
    \| \|
    \ \\

    什么时候必须转义

    场景 说明
    行首的 # 否则被当成标题
    行首的 - + * 否则被当成列表
    表格内的 \| 否则被当成列分隔
    文中单独的 * 否则可能触发斜体

    行内的普通符号通常不用转义，只有在会引起歧义时才需要。

    HTML 混排

    Markdown 允许直接嵌入 HTML，本站已启用 md_in_html 扩展，支持度较好。

    常用场景

    1. 强制换行

    第一行<br>第二行

    2. 带属性的图片

    <img src="/path/to/img.svg" alt="说明" width="400">

    3. 自定义容器

    <div class="custom-box">
  容器内容
</div>

    注意事项

    注意点 说明
    HTML 块内前后要留空行 否则可能被当成普通文字
    HTML 内的 Markdown 需 md_in_html 本站已启用，但块级标签内建议用纯 HTML
    不要用 HTML 做布局 站点样式由主题统一管理，硬写样式会破坏一致性

    推荐做法

    写文档时优先用 Markdown 语法，HTML 只用于 Markdown 表达不了的情况（如 <br>、带宽度的图片）。

    属性列表

    本站启用了 attr_list 扩展，可给元素加属性：

    这段文字有自定义类。
{: .highlight }

    也可用于标题加锚点：

    ## 我的标题 {#custom-id}

    之后可用 [链接](#custom-id) 跳转。

    本站未启用 admonition 扩展，!!! note 之类的写法会原样显示为文本。需要醒目提示时用引用块：

    ```markdown

    注意：这里是提示内容。 ```

    小结

    语法 关键点
    表格 分隔行必需、列数一致、竖线要转义
    代码块 围栏式 + 标注语言、内容不解析
    转义 行首符号与表格竖线需转义
    HTML 前后留空行、优先用 Markdown
    属性列表 {: .class }，本站已启用
