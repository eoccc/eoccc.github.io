    Markdown 语法详解

    Markdown 是一种纯文本标记语言，用少量符号表达标题、列表、表格、代码等结构。本站所有页面都由 Markdown 编写后渲染成 HTML。

    本分支系统讲解 Markdown 的语法、写法与细节，帮助你写出渲染正确、风格统一的文档。

    为什么需要系统了解

    Markdown 的入门门槛很低——会写标题和列表就能开始。但真正动手时，问题往往出在细节上：

    • 为什么这个表格没渲染出来？
    • 为什么空行少了一个，整段排版就乱了？
    • 为什么这段代码块里的内容被当成语法执行了？
    • 为什么列表的缩进差一个空格，层级就错了？

    这些都不是「难」，而是规则没被讲清楚。本分支的目标就是把这些规则一次讲透。

    两条贯穿全篇的原则

    1. 空行是段落的分界

    Markdown 中，一个空行表示一个段落的结束。少了空行，两行文字会被合并成一行；多了空行，结构可能被打断。

    2. 缩进是有语义的

    列表嵌套、代码块、续行——都依赖缩进。缩进量不对，渲染结果就会偏离预期。

    这两条会在后续页面反复出现，是绝大多数「渲染不对」的根源。

    写作前的准备

    本站的写作规范（命名、用词、章节组织）另见 Markdown 写作规范；本分支只讲语法与写法，二者配合阅读。

    如果你要写的是 Mindustry 相关文档，还需注意代码块内容不翻译等额外规则，见 Mindustry 汉化规则。
