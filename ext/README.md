# ext/ —— 扩展静态资源目录（预留）

本目录存放**页面内联使用、但规模较大或需按主题分类**的静态资源，与 `assets/`（主题自带资源）分离，便于后续扩展与维护。

## 目录约定

```
ext/
└── svg/        # 示意图、流程图、概念图等自绘 SVG
```

- 全部资源**本地存放、相对路径引用**，禁止外链加载
- 新增分类（如 `ext/img/`、`ext/icons/`）时，请在本文件补充说明并同步到开发者文档

## 现有资源

| 文件 | 用途 | 引用位置 |
|---|---|---|
| `svg/github-release-flow.svg` | GitHub 开发与软件包发布流程示意图 | `dev/github-release-flow/` |
| `svg/dev-paths.svg` | 开发者文档「多种开发方式」概念图 | `dev/github-release-flow/` |

## 绘制约定

- SVG 使用 `viewBox`，标注 `role="img"` 与 `aria-label`（或 `<title>` / `<desc>`）保证可访问性
- 取色与社区品牌一致：主色 `#5b8def`、辅色 `#7f6fe0`、强调色 `#c76fb8`
- 为兼容站点明暗两种主题，图形自带配色，不依赖页面 CSS 变量
- 不使用外部字体、外部图片与脚本引用

> 路径方案（`img/user/` 与 `ext/` 的分工）仍在团队讨论中，本目录按当前约定先行落地，后续如有调整会同步更新本节说明。
