# 服务器

> 目前状态下，社区的大部分服务器资源均采用**低成本路线**运营。

<details markdown='1'>
<summary><strong>怎么加入服务器？</strong></summary>

1. 打开客户端
2. 选择**多人游戏**
3. 输入服务器 IP / 直接从列表加入
4. 等待验证进入

</details>

<details markdown='1'>
<summary><strong>服务器 IP 是多少？</strong></summary>

请前往[官网首页](/zh/index.html)查看最新的服务器地址列表。

</details>

<details markdown='1'>
<summary><strong>服务器版本是什么？</strong></summary>

建议直接输入 IP 尝试连接服务器，根据提示即可判断：

| 提示 | 含义 |
| --- | --- |
| 成功进入 | 版本匹配，无需担心此问题 |
| 「客户端版本过低」 | 你的版本**低于**服务器版本 |
| 「服务端版本过低」 | 你的版本**高于**服务器版本 |

> **注意**：不建议使用 MindustryBE 连接多人游戏，大多数情况下会因版本不匹配而无法连接。

</details>

<details markdown='1'>
<summary><strong>服务器会不会关服？</strong></summary>

1. 服务器有一定的维护周期，或因特殊原因临时关闭，**群内会及时通知**有关信息。
2. 营造一个高性能的服务器联机平台是社区的核心之一。若非某些强制的、不可抗的原因，服务器和共创社区**仍会正常运行**。

</details>
