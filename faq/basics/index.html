    基础问题

    关于 Everyone Create 共创社区

    什么是共创社区？

    共创社区是一个开放、透明、人人都能参与的协作与创造空间。我们相信好想法不应该被埋没，每个人心中的创意、设计、工具与项目，都能在这里被看见、被实现。

    在这里，你可以用共创把想法变成现实：

    • 学习交流 —— 与同好一起探讨、互相启发
    • 完善文档 —— 让后来者少走弯路
    • 开发功能 —— 把想法写成可运行的代码
    • 优化体验 —— 让工具更好用
    • 共建生态 —— 共同搭建一个真正属于大家的平台

    每一份付出都会被尊重，每一个人都能成为社区的共建者与受益者。我们以开放、平等、互助为初心，一起学习、一起成长、一起做出有价值、能落地、可长久运行的事情。

    共创社区是做什么的？

    共创社区，是把有想法、有热情、愿意动手的人聚在一起，把空想变成真实成果的地方。

    我们不只聊天交流，更在一起做实事：完善文档、开发工具、搭建系统、沉淀经验、打造属于我们自己的平台与生态。无论你擅长技术、设计、写作还是思考，都能在这里找到自己的位置。

    社区同时为大家提供稳定的游戏资源与资源镜像分发等基础服务，并开放公共高配服务器供成员免费使用。

    我们所做的一切本质上都是纯公益行为：不收取任何费用、不设置任何付费门槛，社区运营仅接受成员自愿赞助，所有资源与服务都面向成员免费、公平开放。

    简单说：这里不生产「孤独的想法」，只诞生「一起做成的事」。

    我们的初心是什么？

    我们的初心，始于一份简单而纯粹的热爱 —— 想为所有心怀创意、渴望创造、却常常独自前行的人，搭建一个真正平等、开放、有温度的共同家园。

    我们相信，每个人心中都有值得被实现的想法，每个人都不该因为缺少资源、缺少平台、缺少伙伴而让创意搁浅。于是我们选择以共创为核心，让每一个人都能在这里被听见、被支持、被看见。

    我们坚持做纯公益的社区：

    • 提供公共高配服务器
    • 提供稳定的游戏资源与资源镜像分发服务
    • 所有功能完全免费开放，不设任何付费门槛
    • 不谋取任何商业利益，仅接受自愿赞助

    不为流量，不为名利，只为守住最初的那份热爱与真诚： 让创造不再孤单，让公益成为常态，让每一个努力发光的人，都能在这里拥有属于自己的舞台。

    这，就是我们出发的原因，也是我们一直坚守的初心。

    未来的发展方向大概围绕什么为主？

    社区未来的发展，将始终以「共创」为核心、以「公益免费」为底线、以「成员真实需求」为方向，稳步、健康、长久地走下去。

    我们会继续深耕游戏资源与内容生态，不断完善资源镜像、资源包分发、公共高配服务器等免费公益服务，让成员用到更稳定、更高速、更安全的公共资源。

    同时，我们会持续开放更多能力与工具，降低参与门槛 —— 无论你擅长开发、设计、写作还是策划，都能通过共创，把自己的想法变成社区的一部分。

    未来我们不追求商业化、不设置收费壁垒，依旧坚持纯公益、基础功能全免费、自愿赞助的模式，把重心放在体验优化、资源丰富、生态开放、长期稳定上，一步步把社区打造成一个：

    人人可参与、人人可创造、人人可受益的长期稳定公共平台。

    简单说：以共创为魂，以公益为本，以成员为中心，长期、稳健、踏实地走下去。

    加入与参与

    我是一个什么都不会的普通人，可以加入吗？怎么加入？

    当然可以！ 共创社区没有任何门槛，不看技术背景，不看能力高低，只看你是否愿意参与、愿意分享。哪怕你觉得自己「什么都不会」，也完全可以加入 —— 因为在这里，你的存在本身就是一种价值。

    一、普通人也能参与的方式（完全不用技术基础）

    你不需要会写代码、会设计，也能为社区做贡献：

    • [ ] 用你的视角，帮我们找 Bug、提建议（比如觉得哪里不好用、哪里体验差）
    • [ ] 帮我们完善文档、整理资料、翻译内容
    • [ ] 参与社区讨论，分享你的想法、体验和反馈
    • [ ] 做一名「测试员」，帮我们试用新功能、新资源
    • [ ] 哪怕只是活跃在社区里，和大家交流、互相鼓励，也是在给社区注入活力

    共创的核心不是「你有多厉害」，而是「你愿意一起参与」。

    二、加入方式

    目前加入的方式非常简单，全程无过分审核、无套路：

    1. 直接进入我们的社区渠道（群聊 / 论坛 / 平台），自我介绍一句即可
    2. 可以先从潜水、看别人讨论开始，慢慢熟悉社区节奏
    3. 遇到感兴趣的话题，随时可以发言、提问、分享想法
    4. 想参与贡献时，随时可以和社区成员沟通，我们会给你提供指引和帮助

    我们没有任何形式的收费、门槛或考核，所有成员都是平等的，你可以按自己的节奏参与，不用有任何压力。

    最后想说：社区从不是「大佬的专属地」，而是所有人的「共创场」。我们相信，哪怕是一个普通的想法、一次真诚的反馈，都能让社区变得更好。

    你们有年龄限制吗？

    加入社区没有任何年龄门槛。

    无论你是学生、上班族，还是已经工作多年的爱好者，只要你有热情、愿意交流、认可共创理念，我们都欢迎加入。我们看重的是你的态度、想法和参与感，而不是你的年龄。社区里也有很多和你一样的学生开发者，大家互相学习、一起进步，氛围非常友好。

    只要你能遵守社区规则、认真参与，多大年纪都可以来，都可以一起共创。

    未成年人特别说明

    加入无年龄门槛，不等于未成年人加入后不受特殊保护。

    依据《EOCC 共创社区公约》1.2.5 与 3.8 条，不满 18 周岁的成员在社区内享有特殊保护：

    • 处理未成年人违规时优先考虑教育、警示方式，原则上不得对其适用永久拉黑
    • 管理组视情节暂缓或减轻处置，并及时通知其监护人或平台未成年人保护渠道
    • 禁止任何成员诱导未成年人提供个人隐私、诱导消费打赏、索要其私密照片或敏感信息
    • 禁止利用未成年人身份实施欺骗、胁迫，或传播未成年人不良信息

    详见公约 3.8 未成年人保护类违规。

    社区的组成成分是怎样的？有「听君一席话」那种价值吗？

    一、共创社区的组成成分

    我们的社区没有森严的等级，也没有居高临下的管理者，整体更像一个平等协作的公益团队，主要由这几类人构成：

    角色 职责
    社区运营与维护者 负责服务器、资源镜像、平台稳定、规则维护，保证所有免费服务能长期跑下去
    技术 / 内容贡献者 开发工具、制作资源包、完善文档、搭建生态、分享经验
    普通参与者 / 爱好者 提建议、做测试、聊想法、交流心得、互相帮助——社区最基础也最重要的一部分
    自愿支持者 通过自愿赞助、传播推广、帮忙维护秩序，让社区走得更稳更远

    所有人身份平等、目标一致：一起做实事，一起把想法变成现实。

    二、我们存在的价值是什么？

    非常有，而且这正是我们社区最值钱的地方。

    你可能什么都不会、没有技术、没有经验，但只要在这里交流、提问、看大家讨论、跟着项目走一圈，就能获得：

    • 别人多年踩坑总结出来的经验
    • 真正落地可用的思路、方案、逻辑
    • 做项目、做工具、做社区的完整思维方式
    • 很多外面要花钱、报课才能学到的实战认知

    很多东西不是书本知识，而是真正做过事的人，用结果换来的一句话。你可能只是随口问一个问题，得到的一句回答、一个思路、一个方向，就能少走几个月甚至几年的弯路。

    在我们这里：交流产生价值，共创改变认知，一句话就可能值远超「付费圈子」的东西。 但我们依然坚持：免费、开放、公益。

    我已经有自己的产品了，还可以加入吗？

    非常欢迎，而且我们特别支持独立开发者。

    但前提是：

    • 你尊重社区规则
    • 你尊重他人的劳动成果，不盗用、不恶意搬运
    • 不把社区当成免费劳动力，不要求无条件帮你写代码、改 Bug、按你私人需求定制

    你带产品进来，我们支持你：

    • 交流思路
    • 获得真实反馈
    • 互相借鉴、互相提升
    • 合理合规地展示你的成果
    • 享用社区公共的公益服务（服务器、镜像等）

    但我们不提供「保姆式服务」：

    • 不代表你拿了代码用不了，别人就必须帮你改到满意
    • 不代表你提任何需求，别人都要围着你转
    • 不代表公益 = 无底线付出

    共创的本质是平等、尊重、互相成就，而不是单方面索取、白嫖、绑架他人劳动。
