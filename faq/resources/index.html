    下载很慢怎么办？

    若使用社区资源镜像：

    1. 请检查个人的网络环境
    2. 检查您的带宽是否受到了阻挡
    3. 检查您的设备与路由器之间是否有金属阻挡物或隔房间
    4. 删除原下载任务，重新下载

    注：本站选择的第三方云盘均为不限速类型。

    若使用官方原链接：

    1. 检查你与外部互联网的连接是否通畅
    2. 部分官方原链接需特殊网络环境
    3. 使用 ADM Pro 或其他多链路下载器提高下载速度
    下载链接失效怎么办？

    首先，我们需要郑重地向您道歉 —— 这项基础服务我们并没有做好。您可以通过以下任一方式反馈，我们会尽快修复：

    • 前往 问题反馈 提交该问题
    • 凭下载失效页面 / URL 链接的截图或文本信息，在任意聊天群 @ 管理员
    • 凭对应下载链接失效的 URL 文本，在 GitHub 仓库 反馈 Bug
    • 凭对应下载链接失效的 URL 文本和具体信息、图片等，前往 Bilibili 账号 视频下留言反馈

    公益与付费边界

    社区提供哪些资源与服务？

    我们以公益免费、稳定可靠、长期可用为原则，为成员提供以下公共基础服务：

    1. 游戏资源与资源包镜像分发 社区维护并提供稳定、高速的资源镜像服务，包含各类游戏资源、整合包、依赖文件等，方便大家安全下载、快速使用，避免失效链接与不良资源。
    2. 公共高配服务器免费使用 我们运营高性能公益服务器，开放给成员用于学习、测试、项目运行、社区协作等非商业用途，不收取租金、不设置隐性门槛，让没有设备条件的成员也能拥有优质环境。
    3. 开源项目、文档与经验共享 社区内所有公开的代码、文档、教程、经验总结，都可供成员学习、参考、合理使用，帮助大家少走弯路、提升能力。
    4. 协作共创平台与交流环境 提供稳定的交流、反馈、协作渠道，让有想法的人能找到伙伴，让有技术的人能找到项目，让普通人也能参与创造、提出建议。

    所有服务本质均为公益行为，面向社区成员免费开放，不收取任何费用，仅接受自愿赞助维持运行。

    公益的边界是什么？

    我们做的是公益，不是慈善，更不是无条件的「保姆式服务」。公益有温度，但也有清晰、不可突破的边界。

    1. 公益 = 免费提供公共基础服务 我们免费提供：公共高配服务器、游戏资源与资源包镜像分发、公开项目、文档、交流环境等。这是我们自愿承担的社区责任，也是我们坚持的初心。
    2. 公益 ≠ 无限满足个人需求 公益不代表：
    3. 必须按你的私人想法、私人需求去定制功能
    4. 必须帮你解决所有个人使用问题、调试代码、做到你满意为止
    5. 必须为你个人的项目、产品、服务器无条件投入人力物力

    这些已超出社区公益的合理范围，属于私人定制服务，不在社区义务内。 3. 公益 ≠ 纵容无底线白嫖与道德绑架 社区欢迎所有人学习、使用、参与，但不欢迎伸手党、白嫖党、道德绑架：

    • 「东西是公益的，你就该给我弄好」
    • 「我用不了，你必须帮我改到能用」
    • 「反正你是公益，多付出一点怎么了」

    这类逻辑我们不接受、不妥协、不纵容。 4. 公益的底线：互相尊重，等价善意 社区为你提供稳定、免费的公共服务；你尊重社区规则、尊重他人劳动、理性交流、不恶意消耗。这就是公益最健康、也最能长久维持的边界。

    简单说：我们愿意为公共利益全力以赴，但不会为无底线的个人索取买单。

    公益服务和付费服务的边界是什么？

    为了让社区能长期、健康、稳定地运行，我们清晰划分公益协助与付费协助的边界，既保护贡献者，也避免误解与道德绑架。

    一、公益协助（社区内免费支持）

    属于公共层面、通用问题、基础帮助，我们鼓励并免费提供：

    • 解答通用、公开、文档已有的使用问题
    • 修复公共服务、服务器、资源镜像本身的故障
    • 提供通用教程、基础思路、简单使用指引
    • 社区成员之间自愿、友好、自发的互相帮助

    这部分是社区公益的一部分，完全免费，不收取任何费用。

    二、付费协助（不属于公益范围）

    属于个人定制、私人需求、专属服务，已超出公益边界：

    • 按你个人要求定制代码、修改逻辑、专属功能开发
    • 帮你单独调试、部署、排错个人项目 / 产品
    • 针对你私人使用场景的一对一长期指导、维护
    • 超出公共服务范围的专属技术支持

    这类属于私人定制服务，不在社区公益义务内。如需此类帮助，需与相关开发者私下协商、自愿付费。

    三、一句话分清边界

    类型 解决的问题
    公益协助 解决「大家都能用得上」的公共问题
    付费协助 解决「只给你一个人用」的私人需求

    我们支持公益，也尊重每一位开发者的劳动价值 —— 不道德绑架、不白嫖、不把别人的时间与技术当成理所当然。

    如何判断自己需要的是公益协助还是付费协助？

    你可以用三个最简单的标准，快速判断自己的需求属于哪一类：

    1. 看问题是否「公共通用」

    • 属于公益协助：你的问题是大多数人都会遇到的
    • 社区公共服务器怎么用？
    • 资源镜像下载不了、打不开怎么办？
    • 文档里看不懂、公共服务异常。 → 这是社区公共服务问题，我们免费处理。
    • 属于付费协助：问题只针对你个人、你的项目、你的设备
    • 你的私人代码跑不起来
    • 你的产品要按你的想法改
    • 你的环境、你的需求很特殊 → 这是私人定制问题，不在公益范围内。

    2. 看是否需要「专属时间帮你搞定」

    • 公益协助：我们给通用答案、指引、文档、思路，你可以自己照着做。
    • 付费协助：你需要别人专门花时间、一对一帮你调试、帮你改、帮你做。

    专属人力服务 = 付费协助。

    3. 看是「使用」还是「定制」

    • 公益协助：你在使用社区已有的东西 —— 服务器、镜像、文档、公开代码。
    • 付费协助：你要求在现有基础上额外定制 —— 加功能、改逻辑、按你的习惯重做、专属优化。

    超简单一句话判断

    • 问公共问题、用现成服务、看通用答案 → 公益协助（免费）
    • 要私人定制、要专人帮你做、要按你的需求改 → 付费协助

    我们愿意为公共服务负责到底，也请理解：开发者的时间和劳动，不是免费资源。

    付费服务的收费标准是什么？

    社区内的付费协助属于成员个人之间的自愿交易，相关说明如下：

    • 付费服务的价格由提供服务的开发者自行制定，社区不统一定价、不指定价格标准、不参与议价。
    • 需求方与开发者应在服务开始前，自行沟通清楚需求、价格、交付方式与售后范围，达成一致后再进行交易。
    • 社区仅提供交流与协作环境，不介入、不担保任何成员间的私人交易，不为任何交易纠纷、退款、服务质量、违约等问题承担责任。
    • 所有付费行为均属于双方自愿、私下达成的民事约定，请大家谨慎交易、注意风险、自行甄别。
