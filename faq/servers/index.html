    服务器

    目前状态下，社区的大部分服务器资源均采用低成本路线运营。

    怎么加入服务器？
    1. 打开客户端
    2. 选择多人游戏
    3. 输入服务器 IP / 直接从列表加入
    4. 等待验证进入
    服务器 IP 是多少？

    请前往官网首页查看最新的服务器地址列表。

    怎么查看服务器状态、在线人数和版本？

    前往 status.66131466.xyz 即可查看：

    可查看的信息 说明
    服务器状态 各服务器当前是否在线
    在线信息 当前在线人数等实时数据
    版本信息 服务器运行的版本

    遇到连不上、进不去时，先去这里确认服务器是否在线、版本是否为最新，往往比反复重试更快定位问题。

    服务器版本是什么？

    建议先到 status.66131466.xyz 确认服务器当前版本，再与本地客户端版本对比。

    也可以直接输入 IP 尝试连接服务器，根据提示判断：

    提示 含义
    成功进入 版本匹配，无需担心此问题
    「客户端版本过低」 你的版本低于服务器版本
    「服务端版本过低」 你的版本高于服务器版本

    注意：不建议使用 MindustryBE 连接多人游戏，大多数情况下会因版本不匹配而无法连接。

    服务器会不会关服？
    1. 服务器有一定的维护周期，或因特殊原因临时关闭，群内会及时通知有关信息。
    2. 营造一个高性能的服务器联机平台是社区的核心之一。若非某些强制的、不可抗的原因，服务器和共创社区仍会正常运行。
    联机时能用模组吗？

    联机对局采用模组白名单机制，仅白名单内模组可在对局中加载；白名单由管理组公示并定期更新。

    需要注意的是，以模组形式更改游戏内容是不支持的——例如添加新的音频、新的建筑、新的图标等。这类内容请改用官方数据包形式实现。

    完整的分类与禁止情形见资源与模组 · 可以用模组吗？。

    想改建筑属性或加新内容，联机时该怎么做？

    请使用游戏官方自带的 dp 数据包与 cp 数据包两种形式，而不是模组。

    在此基础上可以修改建筑属性、创建新的建筑，以及为建筑、单位或任何对象配置新的贴图或音频。

    一句话：新增内容走官方数据包这条路，不要用模组去做。

    数据包的具体能力与边界见资源与模组 · 支持哪些形式？。
