# 资源与模组

<details markdown='1'>
<summary><strong>可以用模组吗？</strong></summary>

社区对模组（Mod）使用采取**「分类管理、白名单优先」**机制：

| 类别 | 说明 |
| --- | --- |
| **允许** | 纯客户端美化、UI 调整、画质优化等不影响联机平衡与服务器运行的本地模组，原则上允许使用 |
| **白名单** | 社区服务器联机对局采用模组白名单，仅白名单内模组可在联机对局中加载；白名单由管理组公示并定期更新 |
| **禁止** | 任何改变游戏核心机制、获取不正当竞技优势、干扰服务器运行的模组（如自动辅助、内存修改、协议注入、多开协同等） |

> 禁止类模组一经查实，按《EOCC 共创社区公约》3.4.8 作弊条款或 3.7.3 炸服条款处理。
> 模组使用如与社区服务器联机相关，以**管理组最新公示口径**为准；对具体模组是否可联机存疑的，可在群内询问管理员确认。

</details>

<details markdown='1'>
<summary><strong>哪些模组属于「更改游戏内容」，社区不支持？</strong></summary>

**不支持**以模组形式更改游戏内容。典型情形包括：

- 添加**新的音频**（新增背景音乐、音效等）
- 添加**新的建筑**
- 添加**新的图标**

凡是通过模组新增游戏内容、改变游戏本体内容结构的，均属于这一类，**社区不予支持**。

</details>

<details markdown='1'>
<summary><strong>那要扩展内容该怎么做？支持哪些形式？</strong></summary>

支持使用游戏**官方自带的数据包机制**，即 **dp 数据包**与 **cp 数据包**两种形式。这是官方提供的扩展方式，社区认可并支持在此之上做内容定制。

在此基础上，你可以：

| 可做的事 | 说明 |
| --- | --- |
| **修改建筑属性** | 调整建筑的各项数值与行为参数 |
| **创建新的建筑** | 基于数据包新增建筑 |
| **配置新的贴图** | 为建筑、单位或任何对象指定新的贴图 |
| **配置新的音频** | 为建筑、单位或任何对象指定新的音频 |

也就是说：**新增内容不是不行，而是要走官方数据包这条路，不要用模组去做。**

</details>

<details markdown='1'>
<summary><strong>资源包怎么安装？</strong></summary>

1. 下载资源包
2. 放入 **mod 文件夹**（手机、电脑操作不同，不会的可以在社区内询问）
3. 在客户端启用

</details>

<details markdown='1'>
<summary><strong>存档可以导出吗？</strong></summary>

#### 战役数据导出步骤

1. 打开游戏，点击**设置**
2. 点击「**游戏数据**」
3. 点击「**导出战役数据**」
4. 选择你要导出的文件夹
5. 导出为 `.zip` 格式文件

#### 单个地图游玩数据导出

1. 确保你处于**游戏内**
2. 按下 **ESC** 或返回键呼出菜单
3. 点击**保存**，并为你的存档命名

> 后续可在游戏开始页面点击「存档管理」查看你的存档。

</details>
