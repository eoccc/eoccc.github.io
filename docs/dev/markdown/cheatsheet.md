# 速查表

写作时对照查阅。所有写法均**在本站实际可用**。

## 基础语法

| 语法 | 写法 |
|---|---|
| 一级标题 | `# 标题` |
| 二级标题 | `## 标题` |
| 三级标题 | `### 标题` |
| 段落 | 空行分隔 |
| 斜体 | `*文字*` |
| 粗体 | `**文字**` |
| 粗斜体 | `***文字***` |
| 无序列表 | `- 项目` |
| 有序列表 | `1. 项目` |
| 嵌套列表 | 缩进 2 空格 |
| 链接 | `[文字](地址)` |
| 图片 | `<img src="/路径" alt="说明">` |
| 引用 | `> 文字` |
| 分隔线 | `---` |
| 行内代码 | `` `代码` `` |
| 代码块 | ```` ```json ```` |

## 表格模板

```markdown
| 列一 | 列二 |
|---|---|
| 内容 | 内容 |
```

带对齐：

```markdown
| 左 | 中 | 右 |
|:---|:---:|---:|
| a | b | c |
```

## 代码块模板


````markdown
```
纯文本

````

## 本站不支持

| 语法 | 表现 | 替代 |
|---|---|---|
| `~~删除线~~` | 原样显示 | 写「（已废弃）」 |
| `- [ ] 待办` | 原样显示 | 表格列「状态」 |
| `文字[^1]` | 异常 | 「相关阅读」小节 |
| `!!! note` | 原样显示 | 引用块 `>` |
| `https://a.com` | 纯文本 | `[文](地址)` |
| `H~2~O` | 原样显示 | 行内代码 |
| `==高亮==` | 原样显示 | 粗体 `**文字**` |
| 定义列表 | 合并成段 | 两列表格 |

## 强调提示的写法

本站没有提示框扩展，用引用块加粗开头代替：

```markdown
> **注意**：这里是提示内容。
```

```markdown
> **提示**：这里是补充说明。
```

```markdown
> **警告**：这里是风险提醒。
```

## 三条核心规则

| 规则 | 说明 |
|---|---|
| **块级元素之间留空行** | 标题、段落、列表、表格、代码块、引用 |
| **同级缩进必须一致** | 全篇统一 2 或 4 空格，不用 Tab |
| **特殊符号该转义就转义** | 行首符号、表格竖线 |

## 常见现象 → 原因

| 现象 | 原因 |
|---|---|
| 两段粘在一起 | 少空行 |
| 表格不渲染 | 少分隔行或空行 |
| 列表层级错乱 | 缩进不一致 |
| 代码块无高亮 | 未标注语言 |
| 图片 404 | 用了相对路径 |
| 链接 404 | 路径层级错 |
| 多余符号显示 | 未转义 |
| 提示框无样式 | 用了 admonition |
| 斜体乱出现 | 下划线/星号冲突 |
