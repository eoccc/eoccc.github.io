# 简介

**欢迎阅读官方的、尽管尚不完整的 Mindustry Logic 手册。**

这既是 Mindustry Logic 的指南，也是它的参考手册。其中包含与该语言相关的基础与高级信息。本手册旨在对所有编程水平的人都足够全面，我们也在努力让完全不懂代码的人也能看懂。

## 什么是 Mindustry 逻辑？

Mindustry Logic *（mlog）* 是 v6 中加入的一种脚本语言，目的是为游戏引入更高级的自动化与策略。它深受汇编语言的启发——同一时间只有一条指令或操作。这与 Python、Java 或 C++ 等更流行的语言很不相同：那些语言有便捷的方式编写单行语句、函数、条件语句、循环和类。

该语言目前具备的能力有：

- 获取关于方块和单位（包括玩家）的信息

- 控制建筑与炮塔

- 控制单位以及读写单位中的信息

- 在显示屏中显示形状与颜色

- 通过消息方块输出文本

- 读写存储单元中的信息

- 通过开关方块读取玩家输入

- 数学运算，包括一元和二元

- 以及更多功能！

## 入门 Mindustry 逻辑前需要准备什么？

事先具备一些编程经验（至少在概念和理论上）是件好事。这有助于理解本语言的某些技巧与概念。但最重要的是，你需要*耐心和开放的心态*，因为各版本之间可能变化很大，很多事情在你亲自尝试之前可能显得令人生畏且复杂。

如果你不理解这里使用的特定编程术语，可能也需要随手备好 Google。

## 为什么 Discord 的 #logic 频道里大家都这么冲？

大多数时候，这只是因为你的问题答案就在眼前，你只需要安装本手册或更仔细地阅读它。几乎所有时候，你要做的只是彻底 RTFM（读这本绝妙的手册），然后你就会找到答案。如果你确信这里没有涉及，欢迎在 #logic 中提问。

如何提出一个有效的问题：

- 首先，试着借助本手册或 **Google** 自己弄明白。*说明你已经尝试过什么、已经知道什么。*

- 请**不要**发布极其常见的提问，例如“我怎么控制炮塔”或“怎么让单位移动”。再说一次，你可以在本手册中找到答案。

- 提问要**详细**，这样帮助你的人才能掌握有效回答所需的全部背景。

我们尽量做到不粗鲁、不无礼，但不符合这些标准的问题会考验我们的耐心，尤其是当解决方案很简单且手册中已有说明时。**拿手册里已经写清楚的问题去问别人，是在浪费别人的时间。**

可接受的问题结构与态度的示例：

- “嗨，读完手册后，我还是不太明白 double 到底是什么。我就不能用 int 吗？”

- “我在雷达上遇到了麻烦。即使我在炮塔射程内，它也检测不到我的玩家。这是我的代码：”

- “为什么我不能在同一条 print 指令中正确地打印字符串和变量？”

并非每个人时时刻刻都能做到这一点，所以至少尽力让你的问题像样一些，并遵循以下准则中的至少一条。
