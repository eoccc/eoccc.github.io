# MultiBulletType

内置常量：

`placeholder` `spaceLiquid` `damageLightning` `damageLightningGround` `damageLightningAir` `fireball`

## MultiBulletType

*继承自 BulletType*

一种在“发射”时生成多个子弹药的假弹药类型。

| 字段 | 类型 | 默认值 | 备注 |
|---|---|---|---|
| bullets | BulletType[] | [] |  |
| repeat | int | 1 | 子弹数组重复的次数。 |
