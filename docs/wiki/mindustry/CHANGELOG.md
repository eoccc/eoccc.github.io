## 六、构建与贡献方式变更（v1.0.4.2）

v1.0.4.2 引入 GitHub Actions 云端 CI 自动构建流水线，Wiki 条目的贡献方式随之变化：

| 方式 | 说明 |
|---|---|
| **云端自动构建** | 在线编辑 Markdown / SVG 并提交 PR，云端自动完成 `mkdocs build --strict` 校验；PR 阶段仅校验不部署，合并进 `main` 后才自动部署到 GitHub Pages |
| **本地自构建** | 本地装好锁定版本环境（`mkdocs==1.6.1` + `mkdocs-material==9.7.7`）后预览与自检，仍是现阶段优先推荐的方式 |

由此，修改 Wiki 条目**不再强制要求本地环境**：不必安装 Python 与 MkDocs，也不必跑约 850 秒的全站构建。但需注意，本流水线为**预发布版本，系统不稳定，仍需长期测试、反复迭代修改与校验实际输出内容，不保证输出结果完全无误**，现阶段依然优先推荐本地构建。

完整说明见[云端 CI 自动构建流水线](../../dev/ci-build/)。
