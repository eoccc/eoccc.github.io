# TiledWall

## TiledWall

*extends StaticWall*

Renders walls in packed square tiles, sized to be as large as possible given the provided size constraints. Concept and some code taken from Twcash/Aquarion.

|---|---|---|---|
| sizedRegions | TextureRegion[][][][] | null |  |
