# Markdown 语法详解

Markdown 是一种**纯文本标记语言**，用少量符号表达标题、列表、表格、代码等结构。本站所有页面都由 Markdown 编写后渲染成 HTML。

本分支系统讲解 Markdown 的语法、写法与细节，帮助你写出**渲染正确、风格统一**的文档。

## 为什么需要系统了解

Markdown 的入门门槛很低——会写标题和列表就能开始。但真正动手时，问题往往出在细节上：

- 为什么这个表格没渲染出来？
- 为什么空行少了一个，整段排版就乱了？
- 为什么这段代码块里的内容被当成语法执行了？
- 为什么列表的缩进差一个空格，层级就错了？

这些都不是「难」，而是**规则没被讲清楚**。本分支的目标就是把这些规则一次讲透。

## 两条贯穿全篇的原则

**1. 空行是段落的分界**

Markdown 中，**一个空行**表示一个段落的结束。少了空行，两行文字会被合并成一行；多了空行，结构可能被打断。

**2. 缩进是有语义的**

列表嵌套、代码块、续行——都依赖缩进。缩进量不对，渲染结果就会偏离预期。

这两条会在后续页面反复出现，是绝大多数「渲染不对」的根源。
