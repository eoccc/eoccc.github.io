# 自愿赞助

赞助从来不是强求的。收到赞助后，我们会尽力利用资金创造能做到的最大价值。但赞助金额很难弥补项目的实际支出，也希望你们能理解。

## 关于自愿性

**全部赞助属于自愿行为，不存在任何强制、捆绑要求。**

- 不赞助不影响任何使用：社区的全部功能与资源，对所有成员一视同仁
- 赞助**不会换取特殊权限**，也不带来任何身份、权限或待遇上的差别
- 管理员或其他成员**不会**以任何名义、任何形式索要钱财、捐赠或收费

## 资金用途

收到的赞助用于覆盖社区项目的实际开销，主要包括：

- 域名
- CDN
- 服务器
- 项目开发相关基础设施

## 说明

赞助金额与实际支出往往并不对等，我们不会因资金情况调整对成员的服务标准，也不会以任何形式将赞助与使用权挂钩。

如果你愿意支持，我们表示感谢；如果你选择不参与，同样完全没问题。
