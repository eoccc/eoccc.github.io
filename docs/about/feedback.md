# 维护与反馈

本站由社区成员共同维护，欢迎任何人参与共建。

## 如何参与共建

本站的写作规范、提交流程与站点配置，统一收录在[开发者文档](../../dev/)中：

| 想做的事 | 去哪里看 |
|---|---|
| 撰写或修订文档 | [环境搭建](../../dev/start/)与 [Markdown 写作规范](../../dev/writing/) |
| 提交改动 | [提交与上线流程](../../dev/contribute/) |
| 调整导航或站点结构 | [导航与站点配置](../../dev/nav-config/) |
| 开发并发布软件包 | [GitHub 开发与软件包发布流程](../../dev/github-release-flow/) |
| 为文档配图 | [SVG 图标绘制与创作](../../dev/svg-guide/)、[流程图开发与创作](../../dev/flowchart-guide/) |

还不太熟悉流程？[开发者文档 · 总览](../../dev/)给出了两条推荐路径。

## 反馈渠道

发现文档错误、有内容建议，或想报告站点功能异常，可通过以下方式反馈：

- **提 Issue**：前往 [GitHub 仓库](https://github.com/eoccc/eoccc.github.io/issues)，选择对应模板填写（文档错误修正 / 站点功能异常 / 内容或结构建议）
- **直接改**：小改动可不必开 Issue，按[提交与上线流程](../../dev/contribute/)直接发起 Pull Request 更快
- **群内反馈**：在社区群聊中联系管理员

> 提 Issue 与写 PR 的字段说明，见[提交与上线流程 · 提 Issue 与写 PR](../../dev/contribute/#issue-pr)。
> 更多反馈渠道与常见问题，见[常见问题 · 其他问题](../../faq/others/)。
