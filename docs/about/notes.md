# 注意事项

改动本站前，请先了解以下约定与风险点。

## 不要删除 CNAME

仓库根目录的 `CNAME` 为自定义域名配置，**请勿删除**，否则域名解析失效。

它由 GitHub Pages 读取，把访问地址指向社区域名 `docs.66131466.xyz`。删除或改错都会导致站点无法通过该域名访问。

详见[环境搭建 · 关于 CNAME 文件](../../dev/start/#cname)。

## 不要擅自改动更新日志子站

仓库根目录的 `release/update/` 为版本更新日志子站，其内容生成流程**独立于 MkDocs**，改动请联系维护者。

它与本站其他页面不同：页面正文由 `releases.json` 与 `md/` 下的日志文件动态加载，而非 MkDocs 构建产物。

## 改动前建议先本地预览

涉及排版、导航或新增页面时，先在本地 `mkdocs serve` 确认渲染正常再提交，可避免线上出现标题层级错乱或链接失效。

流程见[提交与上线流程](../../dev/contribute/)。
